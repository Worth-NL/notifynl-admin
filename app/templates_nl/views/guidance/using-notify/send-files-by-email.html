Bestanden per e-mail versturen

Notify biedt een veilige en betrouwbare manier om bestanden per e-mail te versturen.

Upload een bestand en stuur gebruikers een e-mail met een link om het te downloaden.

Notify gebruikt versleutelde links in plaats van e-mailbijlagen omdat:

  • ze veiliger zijn
  • e-mailbijlagen vaak als spam worden gemarkeerd

To send a file by email:

  1. Go to the {{ service_link(current_service, 'main.choose_template', 'templates') }} page.
  2. Add a new email template or choose an existing one.
  3. Select Attach files.
  4. Upload your file.

For security, choose how long the file is available for and ask recipients to confirm their email address before they can download it.

If you use the Notify API

Follow the instructions in our API documentation.

You’ll need a developer on your team to set it up for you.
